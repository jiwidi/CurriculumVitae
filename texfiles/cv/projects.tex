\cvsection{Projects and Open Source}

{\textbf{\href{https://github.com/jiwidi/jiwo}{\faGithub \, jiwo }}} \\ 
Small, low-latency decision models: one forward pass returns a probability per option, with no text generation. At training time, jiwo-0.8b ranked 1st of 27 sub-1B models on the Decision Index. Nearly 300 GitHub stars.

{\textbf{\href{https://github.com/jiwidi/howto}{\faGithub \, HowTo }}} \\ 
Rust CLI that turns plain English into a shell command with a local model. The models come from sandbox-verified distillation (\href{https://github.com/jiwidi/howto-modelling}{howto-modelling}). LoRA raised a 2B model from 27\% to 74.5\% pass@1 on held-out tasks.

{\textbf{\href{https://lens-database.com}{\faGlobe \, lens-database.com}}} \\ 
Catalog that keeps camera lens data for the future. A Python pipeline scrapes listings from multiple sources, deduplicates them into one canonical catalog and enriches them with an LLM. 10k monthly users.

{\textbf{\href{https://github.com/scikit-learn/scikit-learn}{\faGithub \, scikit-learn }}} \\ Several improvements to the Partial Least Squares (PLS) implementation and helper methods. 

{\textbf{\href{https://github.com/pytorch/audio}{\faGithub \, PyTorch Audio }}} \\ Added new baseline datasets (TED-LIUM 1, 2 and 3) and code to facilitate reproducible experiments on one of the most used ASR benchmarks. 

{\textbf{\href{https://github.com/jiwidi/time-series-forecasting-with-python}{\faGithub \,  Time series with Python  }}} \\ 
A use-case focused tutorial for time series forecasting with Python. Nearly 700 GitHub stars.

{\textbf{\href{https://github.com/jiwidi/Behavior-Sequence-Transformer-Pytorch}{\faGithub \, Behavior-Sequence-Transformer-PyTorch }}} \\ 
Open-source implementation of Alibaba's Behavior Sequence Transformer, which combines user behavior sequences and context features for recommendation. 170+ GitHub stars.

{\textbf{\href{https://github.com/jiwidi/las-pytorch}{\faGithub \, LAS-PyTorch }}} \\ 
Open-source implementation of the Listen, Attend and Spell model for end-to-end speech recognition.
